# لِسان — تطبيق عائلي لتعلّم الإنجليزية

تطبيق لتعلّم الإنجليزية للناطقين بالعربية، مبني على أسلوب الألعاب. **يعمل دون إنترنت، بلا حسابات، بلا اشتراكات، وبلا أي تكلفة تشغيل.**

## المحتوى
| المكوّن | التفاصيل |
|---|---|
| المنهج | 7 وحدات · 28 درساً · من A1 إلى B1 |
| شرح القواعد | بطاقات تفاعلية: كلمات ملوّنة حسب دورها، نطق صوتي، وسؤال «جرّب بنفسك» |
| التمارين | مطابقة، اختيار، إكمال فراغ، ترتيب جملة، استماع، كتابة، نطق |
| اختبار المستوى | تكيّفي (A1 ← B2)، ويفتح الدروس المناسبة تلقائياً |
| المراجعة الذكية | تكرار متباعد على 5 صناديق (1، 2، 4، 8، 16 يوماً) |
| المحادثات | 5 مواقف واقعية، منها اجتماع في موقع إنشائي، مع شرح كل خطأ |
| التحفيز | نقاط XP، سلسلة أيام، قلوب، هدف يومي، 15 شارة |
| العائلة | ملف مستقل لكل فرد على الجهاز نفسه، مع نسخ احتياطي ونقل بين الأجهزة |

## طرق التشغيل
1. **الأسرع (للتجربة والمشاركة):** افتح `lisan-offline.html` في Chrome أو Safari. ملف واحد يمكن إرساله عبر واتساب.
2. **الأفضل (تطبيق على الشاشة الرئيسية):** انشر هذا المجلد مجاناً على GitHub Pages أو Netlify أو Cloudflare Pages، ثم افتح الرابط على الجوال واختر «إضافة إلى الشاشة الرئيسية». بعد أول فتح يعمل التطبيق دون إنترنت.

## الملفات
- `index.html` · `styles.css` · `app.js`: التطبيق
- `course-en.js`: منهج الإنجليزية (لإضافة لغة جديدة: ملف مماثل مثل `course-fr.js`)
- `sw.js` · `manifest.webmanifest`: التشغيل دون إنترنت والتثبيت
- `tools/build-single.js`: يعيد بناء `lisan-offline.html` بعد أي تعديل

## ملاحظات
- البيانات محفوظة في متصفح الجهاز. استخدم «تصدير» من صفحة «ملفي» لحفظ نسخة احتياطية.
- النطق والاستماع يعتمدان على محرك الصوت المدمج في المتصفح (مجاني). التعرّف على الصوت يعمل بأفضل شكل في Chrome.
